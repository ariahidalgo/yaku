LA IDEA DEL PROYECTO

Una ollita digital para cuidar el agua.

YAKU es un sistema web inspirado en el relato andino "El Día del Fin del Mundo", donde las wawas necesitan una ollita para transportar agua sin que se derrame.

El proyecto reinterpreta esta necesidad como un problema actual relacionado con el cambio climático, la sequía y el desperdicio.

Mediante inteligencia artificial, YAKU permite a comunidades y agricultores monitorear información relacionada con el agua, predecir posibles sequías con anticipación y acceder a consejos prácticos para su cuidado.
